# 📖 Descripción

TaskManager API es un sistema básico de gestión de tareas desarrollado en Python desde consola.

El proyecto permite registrar, visualizar y administrar tareas de manera sencilla mediante un menú interactivo. Además, implementa una estructura organizada del proyecto siguiendo buenas prácticas de desarrollo de software y control de versiones utilizando Git y GitHub.

---

# ✨ Características

* Agregar tareas dinámicamente
* Visualizar lista de tareas
* Menú interactivo en consola
* Código organizado y modular
* Estructura profesional del proyecto
* Integración con Git y GitHub
* Documentación técnica básica

# 📋 Requisitos

* Python 3.10 o superior
* Git
* Visual Studio Code (recomendado)

---

# ⚙️ Instalación

## 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/usuario/taskmanager-api.git
```

---

## 2️⃣ Ingresar al proyecto

```bash
cd taskmanager-api
```

---

## 3️⃣ Ejecutar la aplicación

```bash
python src/app.py
```

---

# 🚀 Uso

Al ejecutar el programa aparecerá un menú interactivo:

```bash
1. Agregar tarea
2. Mostrar tareas
3. Salir
```

El usuario podrá registrar nuevas tareas y visualizar las tareas almacenadas durante la ejecución del sistema.

# ❓ FAQ

### ¿El sistema almacena tareas permanentemente?

No. Actualmente las tareas solo se mantienen durante la ejecución del programa.

---

### ¿El proyecto utiliza base de datos?

No. Esta versión funciona únicamente en memoria.

---

### ¿Puedo contribuir al proyecto?

Sí. Las contribuciones son bienvenidas.

---

### ¿El proyecto está pensado para producción?

No. El proyecto tiene fines educativos y académicos.
